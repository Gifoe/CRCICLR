# Claim audit

The strongest claim that would be permitted if all gates passed is:

> At matched subject-identity removal, deleting V3.1 Protected persistent
> structure causes greater task degradation than deleting structurally matched
> Non-Protected persistent structure.

This is a development-resource closure, not an untouched replication.  It
does not establish that all subject information is useful, that invariance is
globally harmful, or that a constructive rescue method works.

In the current closure G1 fails before causal validation, so the conditional
claim above is not supported.  The only supported statement is that the frozen
Protected directions replicate on held-out development-validation subjects;
the matched causal comparison remains unevaluated because a valid control
ensemble cannot be constructed for one frozen run.
