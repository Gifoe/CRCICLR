# Synthetic report

The controlled synthetic test is implemented as a reproducibility target in
the source ledger.  It contains a shared task effect, a subject random slope,
an identity feature, and optional identity/label correlation.  ERM,
prospective-only, random-effect-only, full PERSIST-RE, and DANN are compared;
the simulation is interpreted only as a mechanism illustration and is never
used as EEG evidence or a recipe selector.
