# Phase 2 compact checkpoint: cells 6-10

This checkpoint contains the reviewed compact previews for EEGNet on OpenBMI SSVEP, folds 0-4 (seed 0). Each cell contains ten compact CSV artifacts, a provenance record, and a short closure report.

These are cell-level mechanism-analysis previews, not the final 20-cell result. The final held-out partition was not accessed. Outer-development outcomes were descriptive only and were not used for selection. The trajectory artifacts come from retrained replica trajectories.

`VALIDATION_SUMMARY.json` records the exact inventory, provenance hash, and validation outcome for each cell. `SHA256SUMS.txt` covers every file in this checkpoint except itself.
