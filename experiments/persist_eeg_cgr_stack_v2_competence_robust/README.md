# CGR-Stack V2 (CPV2)

This is the bounded post-R1 competence-robust attempt. It uses two fixed
independent subject-grouped 5-fold systems and three fixed EEGNet expert
objectives (ERM, GRL 0.10 and CORAL 0.10), yielding six legal OOF predictions
per source sample and expert. Calibration, family aggregation and the
subject-robust residual stack are nested at the biological-subject level.

The source gate is binding. WBCIC S2 and all outer/sealed resources remain
closed unless the complete source locks are independently authorized.
