# EEG subject-context decision identifiability, seed 0

This direction-qualification experiment tests whether unlabeled session-1 EEG context predicts a useful correction to a shared linear decision rule on unseen subjects' session 2. It is not the proposed Context Reprogramming model and does not train or update an EEG backbone, BatchNorm buffer, native head, neural context encoder or P/C-modified classifier.

The only cells are canonical EEGNet/OpenBMI_MI, seed 0, folds 0–4. TRAIN_GEOMETRY fits and selects; CHECKPOINT_VALIDATION is inventory-only and historically checkpoint-selection exposed; OUTER_DEVELOPMENT is evaluation-only. Formal final-heldout EEG is never opened. OUTER_DEVELOPMENT has appeared in prior mechanism experiments, so this is a frozen new analysis of a historically exposed development cohort, not prospective confirmation.

The immutable design is in `protocol/PROTOCOL_LOCK.json`. The existing, source-audited all-trial TRAIN embedding caches from the P/C differential-adaptation experiment are reused by SHA, while OUTER embeddings are re-extracted from the canonical checkpoint after all TRAIN choices have been sealed. Per-fold runtime arrays and raw logs remain on the original server; Git contains only reviewed compact results and provenance.

The five-fold result is negative under the locked protocol. The labelled S1 oracle head is 5.775 percentage points worse than the TRAIN-chosen strongest global head on OUTER S2 (20,000-draw biological-subject paired bootstrap 95% CI for the difference: −8.15 to −3.60 pp). The zero-label context-predicted head is 0.30 pp worse than global and 0.40 pp worse than a common mean correction; it exceeds the fold-level shuffled-context 95th percentile in only 1/5 folds. Gate A and Gate B both fail. The exact locked next action is `STOP_CONTEXT_MODEL_DIRECTION`, not model construction.

`outputs/FINAL_REPORT.md` answers Q1–Q10 and includes the five-fold table. `outputs/DECISION_SUMMARY.json` records the gate logic and decision; the 15 CSVs contain subject-, fold-, correction-, null-, and budget-level evidence. `protocol/SOURCE_PROVENANCE.json` and `protocol/REPRESENTATION_PROVENANCE.json` bind the compact results to the frozen checkpoints, splits, input normalizers, native head and neural-state hashes. `outputs/HASH_INDEX.json` covers every compact output file. `FAILURE_DISCLOSURES.md` identifies the preserved failed attempts.

The original-server runtime is `D:\nips-temp\TotalP\P1\pc_context_decision_identifiability_runtime`, accessed via `D:\chenyu-iclr\remote_exec_safe.py`. It retains full TRAIN seals, OUTER audits, task logs and earlier immutable code versions. None of its raw caches or logs are pushed. This negative result is specific to the fixed EEGNet embedding, C=1 linear diagnostic heads, deterministic descriptors and historical development cohort; it is not a universal impossibility theorem.
