# EEGNet P semantics and canonical geometry audit (OpenBMI MI, seed 0)

This is a frozen-mechanism audit, not a model-training or intervention branch. Its question is whether the freshly defined Protected structure P encodes a cross-subject task relation, stable subject context, both, or neither, and whether a low-complexity coordinate transform restores a frozen decoder on held subjects.

## Locked scope

- Canonical EEGNet checkpoints and original OpenBMI_MI split, folds 0–4, seed 0. Checkpoint hashes and normalizer hashes are pinned in [`protocol/PROTOCOL_LOCK.json`](protocol/PROTOCOL_LOCK.json).
- [`protocol/UPSTREAM_SOURCE_AUDIT.json`](protocol/UPSTREAM_SOURCE_AUDIT.json) pins the reused loader/PathFit sources. The server PathFit file differs from the worktree copy only in line endings; LF-normalized bytes are identical.
- EEGNet remains in evaluation mode. The frozen model parameters and BatchNorm buffers are checked before/after each analysis.
- New final-embedding P geometry is refitted using only INNER_TRAIN subjects. Early-stage P is a TRAIN-fitted PathFit pathway to final-P coordinates, not independent evidence of biological persistence. [`protocol/GEOMETRY_PROVENANCE.json`](protocol/GEOMETRY_PROVENANCE.json) separates the current geometry from the reused checkpoint.
- The existing Protected-coordinate convention includes TRAIN-label-informed erasure utility. Class information in P is therefore partly expected from its definition; only held-subject evaluation and rank/energy controls can speak to generalization or Protected specificity.
- CHECKPOINT_VALIDATION subjects contributed to historical checkpoint selection and are reported separately. OUTER_DEVELOPMENT subjects are subject-disjoint evaluation only; they are not used to fit geometry, probes, transforms, or thresholds. Formal final-heldout EEG is excluded.
- TRAIN source-session normalizer follows the canonical checkpoint protocol; capped trial subsets are deterministic and class-balanced at 32 trials per subject/session/class. Centroid-trained linear decoders use TRAIN subject-session-class centroids, a fixed `StandardScaler` and L2 logistic `C=1`; they are never refit on held subjects.
- Parts A/B and the permutation controls reuse the canonical label-stratified held evaluation cap. Part C deliberately uses a deterministic *label-blind* held-subject/session cap (up to 128 rows per cell; here the full 100 rows per cell) so target-unlabeled calibration cannot inherit label-dependent sample selection. Its transformed-minus-untransformed decoder recovery is paired within that Part C population. Absolute Part B decoder BA and Part C baseline BA therefore have different held evaluation inventories and must not be treated as directly matched estimates.

## Audit components

1. `code/run.py` creates fresh fold-specific P and PathFit geometry without changing EEGNet.
2. `code/analysis_runner.py` runs semantic decomposition and frozen decoder probes for temporal BN, spatial ELU/pool1, shared depth/point ELU/pool2, and the 64-D embedding. The embedding-only original head audit is descriptive, not additive causal attribution.
3. `code/transform_runner_v3.py` tests identity, translation, regularized diagonal scaling, orthogonal-plus-translation, and ranks 1/2/4/8 low-rank residual affine transforms. Unsupervised fits and rank selection use only unlabeled TRAIN session statistics; five-way held-TRAIN-subject rank selection compares subject means and Gram covariance without class labels. TRAIN class-centroid correspondence and class-relation rank selection are separate oracle diagnostics. The target-unlabeled subject-statistics diagnostic calibrates without target labels and is not zero-shot. High-dimensional orthogonal/low-rank maps act in a TRAIN-derived at-most-32-D support and are identity outside it. Earlier V1/V2 transform runners were halted before producing scientific outputs because their nominally unsupervised rank selection scored labeled class relations; their waiting task records are preserved, and no V1/V2 result is used.
4. `code/permutation_runner.py` runs 200 biological-subject session-pair and within-cell trial-label permutations at the embedding across all five folds. `code/permutation_runner_v2.py` extends the trial-label null to all earlier stages using an algebraically equivalent Gram implementation. Rank-matched 20-draw random-subspace and energy/covariance controls are also reported.
5. `code/aggregate_compact.py` verifies fold/stage source hashes, row counts, immutable checkpoint and geometry references, population guards, and the absence of final-heldout EEG reads before producing compact cross-fold CSVs.

The `outputs/` directory contains the fold/stage-level compact results and the evidence-based final interpretation. Prior outer-development inspection in earlier mechanism work is a historical exposure caveat; it did not supply fitting data in this audit. No result here establishes causal sufficiency of P or improvement of a future neural model.
