# PERSIST-Meta provisional specification

The candidate uses legal history to describe 17 OpenBMI or 18 WBCIC coarse
adaptation actions, predicts future-session utility, and applies only the best
positive risk-adjusted action. P/U/D/G/R augment an otherwise capacity-matched
generic controller. Empirical component-level utility standard deviation is
used as the risk surrogate; it is not calibrated predictive uncertainty.

The candidate is **not frozen for WBCIC outer evaluation** because PERSIST does
not beat the strongest generic Conformer ensemble. Suppression remains
disabled.
