# Transport layer audit

The predeclared candidates are:

1. `pre_embedding`: EEGNet flattened convolutional state (496-D) or
   EEGConformer pooled token state (40-D).
2. `final_embedding`: the frozen task embedding (OpenBMI 64-D; WBCIC EEGNet
   32-D; WBCIC EEGConformer 64-D).

Selection is source-only.  A layer must pass independent cross-session task-probe
competence, residual stability, subject fidelity, class fidelity, and manifold
gates.  `final_embedding` is the deterministic preference if both candidates
pass.  Future-session performance is not computed and cannot influence this
selection.

The completed audit table is generated by `code/analyze_stage0.py`.
