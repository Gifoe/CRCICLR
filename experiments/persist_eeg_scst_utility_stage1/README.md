# PERSIST-EEG SCST utility Stage-1

This experiment prospectively tests whether source-support-constrained subject
transport improves WBCIC session-2 generalization. It starts from the completed
Stage-0 branch and does not revise its negative historical terminal.

The Stage-1 change is frozen before any new future-session utility: the old
`3NN <= 1.25` screen is retained as sensitivity, while the development
guardrail is `3NN <= 1.30` together with every predeclared competence,
stability, fidelity, matched-random, probe, and off-manifold gate.

Runtime checkpoints and representations are intentionally excluded from Git.
