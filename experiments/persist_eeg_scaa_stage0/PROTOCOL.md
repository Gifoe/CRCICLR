# SCAA Stage-0 protocol

The experiment uses an out-of-fold ERM anchor for every target subject, target
S1-only supervised adaptation, independent S2 certification, and frozen-model
S3 evaluation. Balanced-accuracy utility, subject-level inference, the raw
certificate `Delta_S2 > 0`, and all strong-support gates will be machine-locked
before S2/S3 utility is inspected.
