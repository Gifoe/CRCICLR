# PERSIST-EEG SCAA Stage-0

This independent Stage-0 tests whether same-target adaptation utility measured
on WBCIC S2 prospectively transfers to S3. It does not revive prior invariance,
selector, guard, or transport methods, and it does not implement SCAA.

Only the frozen 41-subject WBCIC development pool is legal. The sealed outer 10
and OpenBMI are forbidden in this experiment.
