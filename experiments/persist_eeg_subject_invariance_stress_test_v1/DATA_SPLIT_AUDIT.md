# Data split audit

The experiment loads only the pre-materialized 8,000-row OpenBMI V8_SEARCH cache and requires exact equality with the 40-subject list frozen in `STRESS_TEST_PROTOCOL_FROZEN.json`. It does not call the historical split loader because that loader enumerates the internal holdout membership.

Each outer fold contains eight outcome subjects, eight subject-disjoint inner-validation subjects, and 24 inner-train subjects. Both source sessions are legal for inner training and validation. Only outcome Session 2 is scored. The exact machine audit is generated by `code/preflight.py` before training.
