# V1 diagnostic summary

V1 ended at `NO_ELIGIBLE_PROTECTED_LOSS_OBSERVED`. The fixed GRL λ=0.3 did not
reliably reduce identity; the EEG-DG-style family harmed task performance but
did not reduce identity; SCLDGN reduced identity but had incomplete Protected
assignment. Protected and matched non-Protected raw latent retention both
dropped, demonstrating that cross-model latent R² was not selective-deletion
evidence. These observations motivate, but do not validate, the V1.1 redesign.
