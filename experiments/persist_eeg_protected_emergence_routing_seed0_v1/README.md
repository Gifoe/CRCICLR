# Protected emergence and selective routing (seed 0)

This frozen mechanism-discovery experiment reuses the exact final classifier-input Protected coordinates, native checkpoints, normalizers, canonical bases, and subject splits from the preceding native-utilization and pathway audits. It measures trial-level, TRAIN-only layer-to-P recovery with nested subject-CV ridge selection; then tests whether label-aware oracle complement suppression has a deployable counterpart in a TRAIN-only L2-logistic selective-routing gate.

Scope is EEGNet, EEGConformer, and FBCNet on OpenBMI MI and SSVEP, five folds, seed 0, outer-development evaluation only. FBCNet/MI/fold4 remains `EMPTY_PROTECTED`. No backbone/head/probe is trained or refit, Protected is never redefined, and final-heldout data are never loaded.

For runtime only, the 100 seed-isolated random-routing controls are evaluated by four CPU threads after frozen activations are extracted. This preserves each draw's inputs, seeds, solver, and output order; it changes neither the protocol nor the numerical definition of a control.
